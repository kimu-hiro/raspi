# 練習01 SDカードを丸ごとバックアップする（Macで）

## そもそも何のため
ラズパイを**好き勝手に壊して練習する**ための「戻る場所」を作る。
SDカードは、ラズパイの**脳みそ丸ごと**。その中身を、1つのファイル
（イメージファイル、`.img`）にして Mac に写しておけば、どれだけ
壊しても、そのファイルを SD に書き戻せば元どおり。
これがあるから、安心して暴れられる。

## 全体の流れ（たとえ話）
SDカード ＝ ラズパイの脳みそ。その中身を、まるごと1つのファイル（イメージファイル）にする。

```
ラズパイの電源を切る
  ↓
SDを抜いて、Macに挿す
  ↓
どのディスクがSDか、確認する（いちばん大事）
  ↓
SD の中身をイメージファイルにして Mac に保存する
  ↓
（いつでも）イメージファイルを SD に書き戻して、元に戻せる
```

## なぜこの順番か
`dd`（あとで出る、丸ごとコピーの道具）は、**指定を間違えると
Mac本体を消す**くらい強力。だから「どのディスクか確認」を、
コピーとは**別のステップ**にして、ここだけ慎重に見る。

---

## 準備（ラズパイ側）
1. ラズパイで、安全に電源を切る。
   ```
   sudo shutdown -h now
   ```
   - `sudo`＝superuser do＝管理者として実行
   - `shutdown`＝電源を落とす
   - `-h`＝halt＝止める（`-h now`＝今すぐ止める）
2. 緑ランプが落ち着いたら、電源（USB-C）を抜く。
3. SDカードを抜いて、**Mac に挿す**（SDカードリーダー経由）。

⚠️ 挿したとき「このディスクは読み取れません」と出たら、
必ず **「無視」** を押す。**「初期化」を押すと、SDの中身が消える。**
- Mac は、ラズパイの SD の中身（Linux の形）を読めないので、
  この画面が出るのはふつう

---

## ステップ1：ディスク一覧を見る（🖥 Macで・見るだけ）
```
diskutil list
```
- `diskutil`＝disk utility＝ディスクの道具
- `list`＝一覧を出す

出てきた一覧から、**どれがSDか**を見分ける。目印は2つ：
- **容量**：SDの容量と近い数字（例：32GB のSD → 約 31.9GB）
- **external, physical**（外付けの実物）と書いてある方

⚠️ 番号より、**`external, physical` と容量**で見分ける。
今の Mac は、内蔵ディスクが `disk0`〜`disk3` くらいまで並ぶことが
ある（`internal` や `synthesized`＝作られた仮のディスク、と出る物）。
これらは**Mac本体**なので、絶対に触らない。
SDは `disk4` のように大きい番号になることが多いが、番号だけで
決めない。

## ステップ2：SDのディスク番号をメモ（✍️ 紙かメモに）
見つけた番号を書いておく（例：`disk4`）。
以降のコマンドの `N` は、この番号に置きかえる。

⚠️ **ここを間違えると、関係ないディスクを壊す。**
次に進む前に、もう一度 `diskutil list` で容量を見て確信する。

## ステップ3：SDを「アンマウント」する（🖥 Macで）
```
diskutil unmountDisk /dev/diskN
```
- `unmountDisk`＝ディスクを**論理的に外す**（取り出しはしない）
- なぜ：読み書き中だと、丸ごとコピーできない。いったん
  Mac から「使用中」を外すが、抜きはしないので `dd` は使える
- マウント＝ストレージをフォルダにくっつけて使える状態にする
  こと。アンマウントはその逆（棚から引き出しを“論理的に外す”）

## ステップ4：イメージファイルを作る（🖥 Macで・時間かかる）

置き場所は**外付けHDD**にする（2026-11-28 決定）。
Mac の空きは 15Gi しかなく、`.img`（SDまるごと 28.9G）が入らないため。

### 4-1. 外付けHDDの名前・形式・空きを見る（見るだけ）
```
ls /Volumes
```
- `/Volumes`＝Mac につないだディスクが、フォルダとして並ぶ場所
- HDD の名前がフォルダとして出る（以下、その名前を `HDD名` と書く）

```
diskutil info /Volumes/HDD名 | grep "File System Personality"
df -h /Volumes/HDD名
```
- `diskutil info`＝そのディスクの詳しい情報
- `File System Personality`＝ファイルの整理の仕組み（形式）
  - `ExFAT`・`APFS`・`Mac OS Extended` なら OK
  - **`MS-DOS (FAT32)` だとだめ**：1つのファイルが 4GB までしか
    作れないので、28.9G の `.img` は途中で止まる
- `df -h` の `Avail` が **30G 以上**あれば入る

⚠️ HDD をつないだまま `diskutil list` を見ると、**external, physical
が2つ**出る（SD と HDD）。**容量で見分ける**（SD は約 31.9GB、
HDD は数百GB〜数TB）。ステップ1〜3 の `diskN` は **SD の方**。

### 4-2. 写す
```
sudo dd if=/dev/rdiskN of=/Volumes/HDD名/raspi-backup.img bs=1m
```

⚠️ `of=` は、HDD の**中のファイル**（`/Volumes/HDD名/...`）。
**`/dev/diskX`（HDD そのもの）を書くと、HDD の中の写真が全部消える。**
- `dd`＝data duplicator＝データを丸ごと複製する道具
- `if`＝input file＝入力（コピー元）。ここでは **SD**
- `of`＝output file＝出力（コピー先）。ここでは **HDD の中の imgファイル**
- `rdiskN`＝raw disk＝“生”ディスク（`r`付きは速い版）
- `bs`＝block size＝1回に運ぶ量（`1m`＝1メガずつ。速くなる）
- `sudo`：ディスクを直接読むのに管理者権限が要る
- メモ：Mac の中に置く場合は `of=$HOME/raspi-backup.img` と書く。
  Mac の zsh は `of=~/...` のように **`=` のすぐあとの `~` を
  置きかえない**ので、`~` ではなく `$HOME`（家の住所が入った箱）を使う
  （2026-11-28 確かめた：zsh で `echo of=~/x` → `of=~/x`）

⚠️ `dd` は**何も表示せず黙って進む**（故障じゃない）。
途中経過を見たいときは、実行中に **Control + T** を押すと、
「今どこまで進んだか」が1行出る。
※ 32GB で数十分かかることもある。のんびり待つ。

## ステップ5：ちゃんとできたか確認（🖥 Macで）
```
ls -lh /Volumes/HDD名/raspi-backup.img
```
- `ls`＝list＝一覧、`-l`＝long＝詳しく、`-h`＝human＝読める単位
- サイズが **SDの容量くらい**あれば成功（例：約 32G）

これで「戻る場所」が完成。SDを Mac から取り出して、ラズパイに
戻してOK（取り出しは `diskutil eject /dev/diskN`）。

---

## 壊したあと：イメージファイルから元に戻す（復元）
やることは、ステップ3〜4の **`if` と `of` を逆にするだけ**。

```
diskutil unmountDisk /dev/diskN
sudo dd if=/Volumes/HDD名/raspi-backup.img of=/dev/rdiskN bs=1m
```
- さっきは SD→img（写す）。今回は img→SD（書き戻す）
- SDの中身は**完全に上書き**され、イメージファイルを作ったときの状態に戻る

⚠️ **書き込みは一発アウトの操作**。復元のときこそ、`diskN` の
番号を `diskutil list` で確認してから。内蔵ディスクに書いたら
Macが壊れる。

---

## 気をつけること・次の手順へ
- ディスク番号（`disk4` など）は**挿すたびに変わりうる**。
  毎回 `diskutil list` で確認する。覚えた番号を使い回さない
- 内蔵ディスク（`internal`・`synthesized` と出る物。`disk0`〜`disk3` くらい）は**絶対に指定しない**。特に復元（`of=` に書く方）でまちがえると、Mac が起動しなくなる
- `.img` は SD容量まるごと（28.9G）。置く場所の空き容量に注意
  （2026-11-28：Mac の空き 15Gi では足りないので、外付けHDDに置く）
- `.img` には、SSH の鍵・DB の合言葉・Tailscale の鍵まで**全部**入って
  いる＝家の合鍵のかたまり。**Mac か、自分の外付けHDDの中だけに置く**。
  iCloud・ギットハブ・この raspi のリポジトリの中には置かない
- 次の手順書：**練習02 DVWA を入れ直す**（軽く壊したとき、数分で
  元に戻す手順。これと合わせて「安心して暴れる」が完成する）
