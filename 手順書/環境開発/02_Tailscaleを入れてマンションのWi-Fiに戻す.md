# 手順書 02：Tailscale を入れて、マンションの Wi-Fi に戻す

ゴール：**テザリングなしで、マンションの Wi-Fi のまま Mac からラズパイに SSH で入れる**こと。

---

## 0. 全体の流れ（たとえ話）

マンションの Wi-Fi は、住人の機械どうしが話せない「廊下に壁がある建物」です。
**Tailscale** は、自分の機械どうしだけをつなぐ**専用の見えないトンネル**です。
トンネルはインターネットを通るので、廊下の壁を気にせずにつながります。

```
 今（テザリング）
  Mac ── iPhone ── ラズパイ
         ↓ Tailscale を入れる
 これから（マンションの Wi-Fi）
  Mac      ラズパイ
   │  ✕廊下  │
   └─トンネル─┘
   （インターネット経由）
```

| 段階 | やること | どこで |
|---|---|---|
| 1 | Tailscale のアカウントを作る | Mac のブラウザ |
| 2 | Mac に Tailscale を入れる | Mac |
| 3 | ラズパイに Tailscale を入れる | ラズパイ（SSH の中） |
| 4 | トンネルで入れるか試す | Mac |
| 5 | ラズパイの「合鍵の期限」をなくす | Mac のブラウザ |
| 6 | ラズパイをマンションの Wi-Fi に切りかえる | ラズパイ（SSH の中） |
| 7 | マンションの Wi-Fi のまま入る | Mac |

**1〜6 は、テザリングにつないだままやります。**

---

## 1. Tailscale のアカウントを作る

1. Mac のブラウザで https://tailscale.com を開く
2. 「Get started」（無料で始める）を押す
3. Google・Apple・GitHub などのアカウントでログインする

| 覚えておくこと | 理由 |
|---|---|
| どのアカウントでログインしたか | Mac・ラズパイ・スマホを、全部**同じアカウント**で入れる必要があるから |

- 個人で使う分は無料です（Personal プラン）

---

## 2. Mac に Tailscale を入れる

1. https://tailscale.com/download を開いて、macOS 版を入れる（App Store からでも同じです）
2. Tailscale を開くと、メニューバーにアイコンが出る
3. アイコンを押して、**1 と同じアカウント**でログインする
4. アイコンのメニューに「Connected」と出れば OK

---

## 3. ラズパイに Tailscale を入れる

ここからは、**SSH でラズパイに入っている VS Code のターミナル**で打ちます。
（入っていなければ、手順書 01 の 7-7 のとおり `ssh kimuhiro@172.20.10.3` で入る）

### 3-1. インストールする

```bash
curl -fsSL https://tailscale.com/install.sh | sh
```

| 部分 | 意味 |
|---|---|
| `curl` | インターネットからファイルを取ってくる道具 |
| `-fsSL` | 「失敗したら止まる・余計な表示は出さない・引っ越し先にもついていく」のおまじない |
| `https://tailscale.com/install.sh` | Tailscale 公式の「インストールのやり方」が書かれたスクリプト |
| `\|`（パイプ） | 左で取ってきたものを、右に渡す |
| `sh` | 渡されたスクリプトを、そのまま実行する |

たとえ：公式サイトから「組み立て説明書」を取ってきて、そのまま組み立て係（`sh`）に渡す。
公式が用意しているやり方なので、安心して使えます。
（中で `sudo` を使うので、パスワードを聞かれたら入れる）

終わると `Installation complete!` のように出ます。

### 3-2. トンネルにつなぐ

```bash
sudo tailscale up
```

| 部分 | 意味 |
|---|---|
| `sudo` | 管理者の権限で実行する |
| `tailscale up` | Tailscale のトンネルにつなぐ |

1. `To authenticate, visit:` の下に `https://login.tailscale.com/...` という URL が出る
2. その URL を**Mac のブラウザ**で開く（ターミナルで ⌘ を押しながらクリックすると開けます）
3. **1 と同じアカウント**でログインして、「Connect」を押す
4. ターミナルに `Success.` と出れば OK

### 3-3. トンネルの番号を確かめる

```bash
tailscale ip -4
```

- `100.〇.〇.〇` という番号が出ます。これがトンネルの中でのラズパイの番号です
- メモしておく（下で使います）

| 番号 | どこでの番号？ | たとえ |
|---|---|---|
| `172.20.10.3` | テザリングの中 | 車の中の座席番号 |
| `192.168.3.〇` | マンションの Wi-Fi の中 | マンションの部屋番号 |
| `100.〇.〇.〇` | Tailscale のトンネルの中 | 自分専用の内線番号。どこにいても変わらない |

---

## 4. トンネルで入れるか試す

**Mac のターミナルを新しく開いて**（ラズパイの中ではなく Mac で）打ちます。

```bash
ssh kimuhiro@homepi
```

| 部分 | 意味 |
|---|---|
| `homepi` | Tailscale の中では、`.local` を付けずに名前だけで呼べる（MagicDNS という仕組み） |

- 名前で入れなければ、3-3 の番号で `ssh kimuhiro@100.〇.〇.〇`
- 初回だけ `yes/no` と聞かれる → `yes`
- `kimuhiro@homepi:~ $` と出れば、**トンネルでの接続に成功**

---

## 5. ラズパイの「合鍵の期限」をなくす

Tailscale は安全のため、つないだ機械の合鍵を**180 日で期限切れ**にします。
期限が切れると、ラズパイがトンネルから外れて、外から入れなくなります。
ラズパイはずっと置いておくサーバーなので、期限をなくしておきます。

1. Mac のブラウザで https://login.tailscale.com/admin/machines を開く
2. `homepi` の行の右にある「…」を押す
3. 「**Disable key expiry**」（鍵の期限をなくす）を押す
4. `homepi` の行に「Expiry disabled」と出れば OK

- Mac やスマホは、期限ありのままで大丈夫です（期限が来たら、ログインし直すだけ）

---

## 6. ラズパイをマンションの Wi-Fi に切りかえる

### 6-0. なぜ2段階にするの？（失敗から学んだこと）

最初は `sudo nmcli --ask device wifi connect ...` の1行でやろうとしました。
でも、**パスワードを聞かれる前に SSH が切れて**、失敗しました（2026-10-26）。

```
 ① ラズパイ：テザリングから離れる
 ② ラズパイ：「パスワードは？」と聞く
    → ①で電話が切れたので、
      質問が Mac に届かない
 ③ パスワードがないので、つなげない
```

そこで、**先にパスワードを書いた「接続メモ」を作っておき、そのあとで切りかえる**2段階にします。
たとえ：引っ越しの前に、新しい家の鍵を先に受け取っておく。

### 6-1. マンションの Wi-Fi の「接続メモ」を作る

**ラズパイの中**（SSH のターミナル）で、1行ずつ打ちます。まだ SSH は切れません。

```bash
read -s -p "Wi-Fi password: " WIFI_PW
```

| 部分 | 意味 |
|---|---|
| `read` | キーボードから文字を受け取る |
| `-s` | 打った文字を画面に出さない（パスワードなので） |
| `-p "..."` | 先に表示する案内の文字 |
| `WIFI_PW` | 受け取った文字を入れておく箱の名前 |

→ `Wi-Fi password:` と出たら、**マンションの Wi-Fi のパスワード**を打って Enter（何も表示されません）。

```bash
sudo nmcli connection add type wifi \
  ifname wlan0 con-name mansion-wifi \
  ssid "elecom2g01-1d330a" \
  wifi-sec.key-mgmt wpa-psk \
  wifi-sec.psk "$WIFI_PW" \
  connection.autoconnect-priority 10
```

| 部分 | 意味 |
|---|---|
| `connection add type wifi` | Wi-Fi の接続メモを新しく作る（まだつながない） |
| `\`（行の最後） | 「次の行に続くよ」という印。長いので折り返している |
| `ifname wlan0` | ラズパイの Wi-Fi の部品（`wlan0`）を使う |
| `con-name mansion-wifi` | このメモの名前 |
| `ssid "..."` | マンションの Wi-Fi の名前 |
| `wifi-sec.key-mgmt wpa-psk` | 普通の「パスワード式」の Wi-Fi だよ、という指定 |
| `wifi-sec.psk "$WIFI_PW"` | パスワードは、さっきの箱の中身を使う（コマンドに直接書かないので、履歴に残らない） |
| `connection.autoconnect-priority 10` | 優先度。テザリングとマンションの両方が見えたら、マンションを選ぶ |

→ `Connection 'mansion-wifi' ... successfully added.` と出れば OK。

```bash
unset WIFI_PW
```

| 部分 | 意味 |
|---|---|
| `unset` | 箱の中身（パスワード）を消す。使い終わったので片付ける |

### 6-2. 切りかえる

> ⚠️ ここを実行すると、ラズパイがテザリングから離れるので、**SSH は切れます**。それで正常です。

```bash
sudo nmcli connection up mansion-wifi
```

| 部分 | 意味 |
|---|---|
| `connection up mansion-wifi` | さっき作ったメモを使って、つなぐ |

画面が止まる、または `Connection closed` のように出る → **SSH が切れた合図。正常です**

テザリングの設定は消えずに残ります。
マンションの Wi-Fi が使えないときは、ラズパイが自分でテザリングを探しに行きます（予備の通り道）。

---

## 7. マンションの Wi-Fi のまま入る

1. Mac を**マンションの Wi-Fi**（`elecom2g01-1d330a`）につなぎ直す
2. iPhone のテザリングを**オフ**にする
3. 1分ほど待つ
4. Mac のターミナルで打つ

```bash
ssh kimuhiro@homepi
```

`kimuhiro@homepi:~ $` と出れば、**完了！** 🎉
もうテザリングはいりません。

- 廊下の壁があるので、トンネルはインターネットを回り道します。少しだけ反応が遅く感じるかもしれませんが、SSH や家計簿なら困らない速さです

## 困ったとき

| 症状 | よくある原因 | やること |
|---|---|---|
| `sudo tailscale up` の URL を開いても、アカウントが違う | Mac とラズパイで違うアカウントでログインした | 同じアカウントでログインし直す |
| 4 で `ssh kimuhiro@homepi` が `Could not resolve` | 名前で呼ぶ仕組み（MagicDNS）がオフ | 番号（`100.〇.〇.〇`）で入る |
| 4 で何も返ってこない | Mac の Tailscale が「Connected」になっていない | メニューバーのアイコンで接続を確かめる |
| 7 で入れない | ラズパイがマンションの Wi-Fi につながれていない（パスワード違いなど） | iPhone のテザリングをオンにして 3 分待つ → ラズパイが予備のテザリングに戻ってくるので、`ssh kimuhiro@homepi` で入って 6 をやり直す |
| 7 で `Operation timed out`。Tailscale の一覧で `homepi` が offline | 切りかえ直後に、ラズパイの Wi-Fi が一度途切れた（2026-10-26 に実際に起きた） | ラズパイの電源を入れ直して 3 分待つ（実際にこれで入れた） |
| 7 で入れず、テザリングにも戻ってこない | ラズパイがマンションの Wi-Fi にはつながったが、Tailscale が動いていない | ラズパイの電源を入れ直して 3 分待つ。それでもだめなら Claude に相談 |
