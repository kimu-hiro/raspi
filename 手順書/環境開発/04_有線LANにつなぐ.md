# 手順書 04：有線 LAN につなぐ

ゴール：**ラズパイを LAN ケーブルでつないで、弱い Wi-Fi を通らずに入れる**こと。

---

## 0. 全体の流れ（たとえ話）

マンションの Wi-Fi は、夕方になると満員電車のように混みます。
LAN ケーブルは、ラズパイ専用の**自分だけの道**です。混んでいても関係ありません。

```
 今（Wi-Fi）
  ラズパイ
    │ 電波（混む・弱い）
    ↓
  マンションの Wi-Fi の親機

 これから（有線）
  ラズパイ
    │ LAN ケーブル（自分だけの道）
    ↓
  壁の差し込み口
```

| 段階 | やること | どこで |
|---|---|---|
| 1 | ケーブルを差す | ラズパイと壁 |
| 2 | 電源を入れ直す | ラズパイ |
| 3 | 入れるか試す | Mac |
| 4 | 有線になっているか確かめる | ラズパイ（SSH の中） |

**設定はいりません。** ラズパイは、ケーブルが差さると自分で有線につなぎます。
（ネットの係 NetworkManager が、最初から「有線なら自動でつなぐ」設定になっているため）

---

## 1. ケーブルを差す

1. ケーブルの片方を、ラズパイの **LAN の穴**（USB の横の、一番大きい四角い穴）に差す
2. もう片方を、**壁の差し込み口**に差す
3. 「カチッ」と音がするまで押し込む

---

## 2. 電源を入れ直す

ラズパイは今、トンネルから外れているはずなので、電源を入れ直します。

1. USB-C を抜いて、10秒待って、また差す
2. **3分待つ**

### LAN の穴のランプを見る

LAN の穴の横には、小さいランプが2つあります。

| ランプ | 意味 |
|---|---|
| ついている | ケーブルの先とつながった ✅ |
| チカチカする | データが流れている ✅ |
| 両方消えたまま | ケーブルの先とつながっていない ❌ → 困ったとき |

---

## 3. 入れるか試す

**Mac のターミナル**（VS Code）で打ちます。

```bash
ssh kimuhiro@homepi
```

`kimuhiro@homepi:~ $` と出れば OK。

- トンネル（Tailscale）を通るので、入り方は今までと同じです
- 道が Wi-Fi から有線に変わっても、トンネルの番号（`100.101.64.85`）は変わりません

---

## 4. 有線になっているか確かめる

**ラズパイの中**で打ちます（読むだけ。何も変えません）。

```bash
nmcli device status
```

| 部分 | 意味 |
|---|---|
| `nmcli` | ネットの係（NetworkManager）に話しかける道具 |
| `device status` | 道ごとの、今の様子を一覧で出す |

見るところ：

| DEVICE（道） | STATE（様子） | 意味 |
|---|---|---|
| `eth0` | `connected` | 有線がつながった ✅ |
| `wlan0` | `connected` か `disconnected` | Wi-Fi。どちらでも OK |

### 有線と Wi-Fi の両方がつながっていたら？

心配いりません。**ラズパイは有線を優先します。**

```
 外へ出る道を選ぶとき
  有線（eth0）    点数 100 ← 小さい方が勝ち
  Wi-Fi（wlan0）  点数 600
```

たとえると、空いている自分専用の道と、混んだ大通りがあれば、自分専用の道を使う感じです。
Wi-Fi は**予備の道**として残しておきます（ケーブルが抜けたときに助かる）。

確かめたいときは、これを打ちます。

```bash
ip route | grep default
```

| 部分 | 意味 |
|---|---|
| `ip route` | 外へ出る道の一覧 |
| `\| grep default` | 「ふだん使う出口」の行だけ |

→ 一番上の行に `dev eth0` と出れば、有線が使われています。

---

## 5. 次にやること

有線で入れたら、すぐに**手順書 03 の 2（日記を消えないようにする）**をやります。
有線にしてもまだ落ちるかどうかを、日記で確かめるためです。

```
 有線にした
   ↓
 手順書 03 の 2 で日記をノートにする
   ↓
 数日ようすを見る
   ├ 落ちない → 犯人は Wi-Fi 🎉
   └ 落ちた → 手順書 03 の 3 で日記を読む
              （電源が犯人かも）
```

---

## 困ったとき

| 症状 | よくある原因 | やること |
|---|---|---|
| LAN の穴のランプが両方消えたまま | ケーブルが奥まで入っていない | 両はしを「カチッ」と言うまで差し直す |
| 差し直してもランプが消えたまま | 壁の差し込み口が使えない（中で線がつながっていない） | 別の差し込み口があれば試す。なければ Claude に相談 |
| ランプはつくのに、`ssh` で入れない | 有線で住所（IP アドレス）をもらえていない | iPhone のテザリングで入って（手順書 02 の困ったとき）、`nmcli device status` を Claude に貼る |
| `eth0` が `connecting` のまま | 住所をくれる機械が返事をしない | 上と同じ |
