# 手順書 01：OS を書き込んで、ラズパイを起こす

ゴール：**Mac からラズパイに SSH で入れる**ところまで。

---

## 0. 全体の流れ（たとえ話）

ラズパイは「体」だけ届いた状態です。脳みその中身（OS）はまだ空っぽです。

```
 [ Mac（先生） ]
      │
      │ ① Imager で書き込む
      │   （OS ＋ 最初の設定）
      ▼
 [ microSD（脳みそ） ]
      │
      │ ② ラズパイに差して、電源オン
      ▼
 [ ラズパイ（体） ]
      ▲
      │ ③ Wi-Fi 経由で SSH
      │   （遠くから話しかける）
      │
 [ Mac（先生） ]
```

| 段階 | やること | たとえ |
|---|---|---|
| ① | Mac で、microSD に OS と最初の設定を書き込む | 先生が、脳みそに「名前・合言葉・家の Wi-Fi」を書いたメモを入れておく |
| ② | microSD をラズパイに差して、電源を入れる | 体が目を覚まして、メモを読む |
| ③ | Mac から SSH で入る | 画面もキーボードもないので、電話（SSH）で話しかける |

画面なし（ヘッドレス）で使うので、②で何か表示されるわけではありません。**③ でつながれば成功**です。

---

## 1. 帰る前に決めておくこと（dキャリアでできる）

Imager に入力する内容です。先にメモしておくと、家で迷いません。

| 項目 | 何に使う？ | 例 | 自分の答え |
|---|---|---|---|
| ホスト名 | ラズパイの「名前」。SSH で呼ぶときに使う | `homepi` | |
| ユーザー名 | ラズパイに入るときの名前（`pi` は誰でも思いつくので避ける） | `kimuhiro` | |
| パスワード | ユーザーの合言葉 | （人に見せない） | |
| Wi-Fi の名前（SSID） | ラズパイがつなぐ家の Wi-Fi | ルーターのシールに書いてある | |
| Wi-Fi のパスワード | 同上 | 同上 | |

- **大文字・小文字を区別します**（Linux のルール）。メモ通りに打てるようにしておく
- ホスト名は英小文字・数字・`-` だけにする

### 持ち物チェック

| もの | 確認 |
|---|---|
| ラズパイ本体 | 届いている |
| microSD（32GB） | 届いている |
| Mac に microSD を差す口、またはカードリーダー | ☐ 家で確認 |
| USB-C 充電器＋ケーブル | ☐ 手持ちのものでまず試す |

---

## 2. Mac に Raspberry Pi Imager を入れる

**Raspberry Pi Imager** は、microSD に OS を書き込む公式アプリです。
たとえるなら「脳みそにソフトを焼き付ける機械」です。

やり方は A・B のどちらか1つでかまいません。**普段から brew を使っているので A がおすすめ**です。

### A. brew で入れる（おすすめ）

```bash
brew install --cask raspberry-pi-imager
```

| 部分 | 意味 |
|---|---|
| `brew` | Mac のアプリストア（コマンド版） |
| `install` | 入れて、という命令 |
| `--cask` | 「画面のある普通のアプリ（.app）」を入れるときの印。付けないとコマンド用の道具を探しに行く |
| `raspberry-pi-imager` | 入れるアプリの名前 |

終わると「アプリケーション」フォルダに **Raspberry Pi Imager** が入ります。

### B. 公式サイトから入れる

1. https://www.raspberrypi.com/software/ を開く
2. 「Download for macOS」を押して `.dmg` をダウンロードする
3. `.dmg` を開いて、アイコンを「アプリケーション」フォルダにドラッグする

---

## 3. microSD に OS を書き込む

### 3-1. microSD を Mac に差す

- Finder に知らない名前のディスクが出ることがありますが、**そのまま**にしておく（初期化しない）

### 3-2. Imager を開いて、3つ選ぶ

Imager を開くと、選ぶものが3つあります。
（Imager のバージョンで、ボタンの名前や並びが少し違うことがあります。迷ったら画面のスクショを見せてください）

| 選ぶもの | 選ぶ答え | なぜ？ |
|---|---|---|
| デバイス（Device） | **Raspberry Pi 4** | 自分のラズパイの型 |
| OS | **Raspberry Pi OS (other)** → **Raspberry Pi OS Lite (64-bit)** | 画面なし版（Lite）にして、メモリ 1GB を節約する。64-bit は公式のおすすめ |
| ストレージ（Storage） | **差した microSD**（32GB くらいのもの） | 書き込み先 |

> ⚠️ **ストレージ選びは慎重に。** 選んだディスクは**中身が全部消えます**。
> 「32GB 前後」のものを選ぶ。Mac 本体や外付け HDD を選ばないこと。

### 3-3. 最初の設定（カスタマイズ）を入れる

「次へ」を押すと、**「設定を編集しますか？／カスタマイズしますか？」** と聞かれます。
→ **編集する（Edit settings / はい）** を選ぶ。

ここが一番大事です。画面なしで使うので、ここで設定しないと SSH で入れません。

| 設定 | 入れる内容 | 何のため？（たとえ） |
|---|---|---|
| ホスト名 | メモしたホスト名（例：`homepi`） | ラズパイの名札 |
| ユーザー名・パスワード | メモしたもの | 家の鍵 |
| Wi-Fi | SSID・パスワード、国は **JP** | 家の Wi-Fi の合言葉を、先に教えておく。国を合わせないと電波の決まりが違ってつながらないことがある |
| ロケール（地域） | タイムゾーン **Asia/Tokyo**、キーボード **jp** | 時計を日本時間にする |
| SSH | **有効にする**、**パスワード認証を使う** | 電話（SSH）を受けられるようにする |
| Raspberry Pi Connect | **オフのまま** | 公式の「外からつなぐ」サービス。Tailscale と役割がかぶるので使わない |

- SSH の「公開鍵認証」の方が安全ですが、今回はまず**パスワード認証**でつながることを優先します。鍵は Tailscale を入れた後の手順で切り替えます

### 3-4. 書き込む

1. 「書き込む（Write）」を押す
2. 「データが消えます」と聞かれる → **はい**
3. Mac のパスワードを聞かれたら入れる（ディスクに書き込む許可）
4. 書き込み → 確認（Verify）が終わるまで待つ（10〜20 分くらい）
5. 「取り出してください」と出たら、microSD を抜く
   - Imager が自動で「取り出し」まで済ませるので、Finder から microSD が消えます。それで正常です（抜いても大丈夫の合図）

---

## 4. ラズパイを起こす

1. microSD をラズパイの**裏側**の差し込み口に差す（金色の端子が基板側）
2. USB-C 充電器をつなぐ（電源ボタンはありません。つなぐと起動します）
3. ランプを見る

| ランプ | 意味 |
|---|---|
| 赤がつきっぱなし | 電気が来ている（OK） |
| 赤が消える・点滅する | 電気が足りない可能性 → 充電器を変える |
| 緑がチカチカ | microSD を読んでいる（考え中） |

4. **3〜5 分待つ**。最初の起動は、設定の読み込みや再起動を自動でやるので時間がかかります

---

## 5. Mac から SSH で入る

Mac のターミナルで打ちます。**Mac とラズパイが同じ Wi-Fi にいること**が条件です。

### 5-1. ラズパイが見つかるか確かめる

```bash
ping -c 3 homepi.local
```

| 部分 | 意味 |
|---|---|
| `ping` | 「いる？」と呼びかけて、返事が来るか見る |
| `-c 3` | 3回だけ呼ぶ（付けないと止まらない） |
| `homepi.local` | ホスト名＋`.local`。同じ Wi-Fi の中で、名前で相手を探す書き方 |

- `64 bytes from ...` が3回出れば、ラズパイは起きて Wi-Fi にいます
- `cannot resolve` や返事なし → 下の「困ったとき」へ

### 5-2. SSH で入る

```bash
ssh kimuhiro@homepi.local
```

| 部分 | 意味 |
|---|---|
| `ssh` | 遠くの機械に、安全な電話をかける |
| `kimuhiro@` | 「このユーザーとして入ります」（Imager で決めたユーザー名） |
| `homepi.local` | かける相手 |

1. 初回だけ `Are you sure you want to continue connecting (yes/no...)?` と聞かれる → `yes` と打つ（「この相手を覚えておく？」という確認）
2. パスワードを聞かれる → Imager で決めたものを打つ（**打っても画面に何も出ません**。そういう仕様です）
3. `kimuhiro@homepi:~ $` のように表示が変われば **成功！** 🎉

---

## 6. 健康診断（入れたらすぐ）

ラズパイの中で打ちます。

| コマンド | 何を見る？ | OK の目安 |
|---|---|---|
| `vcgencmd get_throttled` | 電気が足りているか | `throttled=0x0`（0 以外なら電源不足の記録あり → 充電器を変える） |
| `free -h` | メモリの空き | `Mem` の total が 900Mi 前後 |
| `df -h /` | microSD の空き容量 | `Size` が 28G 前後 |

- `-h`：数字を「人が読みやすい単位（M・G）」で出す

終わったら、`exit` で SSH を切る（電話を切る）。

ラズパイの電源を切るときは、**いきなりケーブルを抜かず**に、先にこれを打つ：

```bash
sudo shutdown -h now
```

| 部分 | 意味 |
|---|---|
| `sudo` | 管理者の権限で実行する |
| `shutdown -h now` | 今すぐ（now）止まる（halt） |

緑ランプが止まってからケーブルを抜く。急に抜くと、脳みそ（microSD）のデータが壊れることがあります。

## 7. マンションの Wi-Fi で入れないとき（テザリングで入る）

### 7-1. なぜ入れないの？

マンション備え付けの Wi-Fi は、**住人どうしの機械が話せない**設定（プライバシーセパレーター）になっていることが多いです。
隣の部屋の人に、自分の Mac をのぞかれないための仕組みです。
そのせいで、自分の Mac と自分のラズパイどうしでも話せません。

```
 マンションの Wi-Fi
  Mac ──✕── ラズパイ
   │          │
   ▼          ▼
  インターネット（両方とも出られる）
```

見分け方：

| `arp -a` の結果 | `ping 番号` の結果 | 考えられること |
|---|---|---|
| `homepi` が出る | 返事なし | セパレーターに止められている |
| `homepi` が出ない | ― | ラズパイが Wi-Fi につながっていない |

### 7-2. 作戦：iPhone のテザリングを「一度だけの通り道」にする

iPhone のテザリング（インターネット共有）は、つないだ機械どうしで話せます。
そこで一度だけ入って、Tailscale を入れてしまいます。
Tailscale はインターネット経由でつなぐので、そのあとはマンションの Wi-Fi に戻しても入れます。

```
 ① iPhone のテザリングに
    Mac とラズパイをつなぐ
         ↓
 ② Mac から SSH で入る
         ↓
 ③ Tailscale を入れる（手順書 02）
         ↓
 ④ ラズパイをマンションの Wi-Fi に戻す
    （手順書 02 の最後）
         ↓
 ⑤ 以後は Tailscale 経由で入る
```

たとえ：マンションの廊下では話せないので、一度だけ自分の車（iPhone）に2人で乗って、合鍵（Tailscale）を渡しておく感じです。

### 7-3. iPhone の名前を確かめる

テザリングの Wi-Fi の名前（SSID）は、**iPhone の名前**になります。

1. iPhone の「設定」→「一般」→「情報」→「名前」を見る
2. 名前に**日本語・記号・絵文字**が入っていたら、英数字だけに変える（例：`kimuhiro-iphone`）

| なぜ？ |
|---|
| ラズパイは、日本語などが入った Wi-Fi 名をうまく読めないことがあるから |

### 7-4. iPhone のテザリングをオンにする

1. 「設定」→「インターネット共有」を開く
2. 「ほかの人の接続を許可」を**オン**
3. 「**互換性を優先**」を**オン**
4. 「"Wi-Fi"のパスワード」をメモする
5. **この画面を開いたまま**にしておく

| 設定 | 何のため？ |
|---|---|
| 互換性を優先 | 電波を 2.4GHz にする。ラズパイがつながりやすくなる |
| 画面を開いたまま | iPhone は、この画面を閉じてしばらくだれもつながっていないと、テザリングの電波を隠してしまうから |

### 7-5. Mac をテザリングにつなぐ

1. Mac のメニューバーの Wi-Fi マークを押す
2. iPhone の名前を選ぶ（「パーソナルホットスポット」の欄に出ることもあります）

### 7-6. microSD を書き込み直す

手順 3 を**もう一度**やります。変えるのは Wi-Fi のところだけです。

1. ラズパイの USB-C ケーブルを抜く（SSH で入れないので、今回は抜くしかない）
2. microSD をラズパイから抜いて、Mac に差す
3. Imager を開いて、手順 3-2 と同じく「デバイス → OS → ストレージ」を選ぶ
4. カスタマイズの画面で、左の一覧の **Wi-Fi** だけ書きかえる（下の表）
5. 「書き込む」→ 終わったら抜く（手順 3-4 と同じ）

| 設定 | 入れる内容 |
|---|---|
| Wi-Fi の SSID | **iPhone の名前**（7-3 で確かめたもの） |
| Wi-Fi のパスワード | **テザリングのパスワード**（7-4 でメモしたもの） |
| ほか（ホスト名・ユーザー名・SSH など） | 前回と同じ |

- Imager v2.0.12 では、前回の設定は**残っていませんでした**（2026-10-26）。手順 3-3 の表を見ながら、全部もう一度入れる

### 7-7. 起こして、入る

1. microSD をラズパイに差して、電源をつなぐ
2. **5 分待つ**
3. 手順 5（`ping` → `ssh`）をやる

- `homepi.local` で見つからなければ、`arp -a` で番号を探して、番号で `ping`・`ssh` する
- テザリング中の番号は `172.20.10.〇` の形になります（マンションの `192.168.3.〇` とは別の番号）

```bash
ssh kimuhiro@172.20.10.〇
```

- `ssh` は、パスワードを打つやり取りがあるので、**Claude のチャットではなく、VS Code のターミナル**で打つ

入れたら、手順 6 の健康診断をして、**テザリングにつないだまま**手順書 02（Tailscale）に進みます。

## 困ったとき

| 症状 | よくある原因 | やること |
|---|---|---|
| `ping` で `cannot resolve` | まだ起動中／Wi-Fi につながっていない | もう 3 分待つ → だめなら Wi-Fi の SSID・パスワード・国（JP）を Imager で入れ直して書き込み直す |
| `ping` は通るが SSH で `Connection refused` | SSH を有効にし忘れた | Imager の設定で SSH を有効にして書き込み直す |
| パスワードが通らない | 大文字・小文字の違い／キーボード設定 | メモと見比べる。だめなら書き込み直す |
| `REMOTE HOST IDENTIFICATION HAS CHANGED!` | 書き込み直したので、ラズパイの「顔」が変わった | `ssh-keygen -R homepi.local` で古い記憶を消してから、もう一度 `ssh` |
| 赤ランプが消える・点滅 | 電気不足 | 充電器を出力の大きいもの（5V 3A）に変える |
| `arp -a` に `homepi` は出るのに、番号で `ping` しても返事がない | マンションの Wi-Fi のプライバシーセパレーター | 手順 7（テザリングで入る） |
| テザリングで、番号を全部呼んでも Mac しかいない | Imager に入れた SSID が iPhone の名前と違う（実例：`kimuhiro-iphone` なのに `kimuhiro-WiFi` と入れていた）／「互換性を優先」がオフ | iPhone の「設定 → 一般 → 情報 → 名前」と、1文字ずつ見比べて書き込み直す |

書き込み直しは何度やっても大丈夫です。microSD を Mac に差して、手順 3 からやり直せばいいだけです。
