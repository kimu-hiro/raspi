# 手順書 09：電源ボタンとケースを付ける

ゴール：**ボタンを押すだけで、ラズパイの電源を安全に切れる**ようにする。
ついでに、冷やすケース（ファン付き）に入れる。

状態：未着手

---

## 0. 全体の流れ

```
① 公式の説明を自分で読む（何をする設定か）
      ↓
② 設定ファイルに1行足す（SSH で）
      ↓
③ 電源を切る
      ↓
④ ケースに入れる（ケースの説明書を見ながら）
      ↓
⑤ ボタンをつなぐ（ブレッドボード＋線2本）
      ↓
⑥ 電源を入れて、ボタンを押してみる
```

たとえ：お店に「閉店ボタン」を付ける。
店長（ラズパイの中の係）が自分で付けたボタンなので、
押すたびにハンコ（パスワード）はいらない。

## 2. 公式の説明を読む（読むだけ）

**ラズパイの中**（`ssh homepi`）で打ちます。
この設定の説明書は、ラズパイの中に最初から入っています。

```bash
grep -n -A 20 "^Name:.*gpio-shutdown" \
  /boot/firmware/overlays/README
```

| 部分 | 意味 |
|---|---|
| `grep` | ファイルの中から文字をさがす |
| `-n` | number。何行目かも出す |
| `-A 20` | after。見つけた行の**あと**20行も出す |
| `"^Name:.*gpio-shutdown"` | 行の頭（`^`）が `Name:` で、そのあと（`.*`＝何文字でも）に `gpio-shutdown` がある行 |
| `\` | 次の行に続く、の印 |

**確かめる**：`Info:` のあたりに、何をする設定かが英語で書いてある。
分からない英語があったら、Claude に貼って一緒に読む。

- overlay（オーバーレイ）＝「上から重ねるもの」。
  ラズパイの部品表に、あとから1枚重ねる設定

## 3. 設定ファイルに1行足す

### 3-1. 元のファイルを写しておく（保険）

```bash
sudo cp /boot/firmware/config.txt \
  /boot/firmware/config.txt.bak
```

- `cp` ＝ copy ＝ 写す
- `.bak` ＝ backup（予備）の印
- 失敗しても、この写しから戻せる

### 3-2. ファイルを開く

```bash
sudo nano /boot/firmware/config.txt
```

### 3-3. いちばん下に1行足す

一番下までカーソルを動かして、次の1行を足す。

```
dtoverlay=gpio-shutdown
```

- dtoverlay ＝ device tree overlay ＝ 部品表に重ねる設定
- gpio-shutdown ＝ GPIO（ピン）で shutdown（電源を切る）

⚠️ いちばん下が `[all]` のあとになっていることを確かめる。
`[cm4]` などの見出しのすぐ下だと、別の機械向けの設定になって、効かない。

保存：`Ctrl + O` → `Enter`、閉じる：`Ctrl + X`

### 3-4. 足せたか確かめる

```bash
tail -n 3 /boot/firmware/config.txt
```

- `tail` ＝ しっぽ ＝ ファイルの最後を見る
- `-n 3` ＝ number。最後の3行

**確かめる**：`dtoverlay=gpio-shutdown` が見える。

### 3-5. （選べる）長押ししないと切れないようにする

ボタンが軽くて、ぶつかっただけで切れてしまうのが心配なら、
「何秒押し続けたら反応するか」を決められる。
使うかどうかは、自分で決める。

まず、2 で読んだ README に、`debounce` の説明があるか確かめる。

```bash
grep -n -A 70 "^Name:.*gpio-shutdown" \
  /boot/firmware/overlays/README | grep -i debounce
```

- `-A 70`：gpio-shutdown の説明は 1848〜1912行目。`debounce` は
  1909行目（始まりから61行あと）にあるので、`-A 20` や `-A 60` では届かない
  （2026-11-27 確かめた。1890行目から `Params:`）

- 2つ目の `grep -i debounce` ＝ 出てきた行の中から、
  debounce（大文字小文字を区別しない）の行だけ

**確かめる**：`debounce` の行が出たら、この設定が使える。
出なかったら、ここは飛ばして、Claude に結果を見せる。

使えたら、3-3 で足した1行を、次のように書きかえる。

```
dtoverlay=gpio-shutdown,debounce=3000
```

| 部分 | 意味 |
|---|---|
| `,` | おまけの設定を足す区切り |
| `debounce` | 押した・離したのブレを無視する時間 |
| `3000` | 3000 ミリ秒＝3秒。3秒押し続けたときだけ切れる |

**決めたこと（2026-11-27）**：3秒も0.1秒も極端なので、**1秒**（`debounce=1000`）にした。

- 起動の方（止まっているときに押す）は、この設定とは関係なく、
  短く押すだけで起動する

この設定は、次に起動したときから効く。
ボタンはまだないので、今は何も起きない。

## 4. 電源を切る

```bash
sudo shutdown -h now
```

緑ランプが止まってから、USB-C を抜く。
**ここから先は、電源を抜いたまま作業する。**

## 5. ケースに入れる

**ケースの箱に入っている説明書を見ながら**組み立てる。

説明書を読むときに、ここだけは見ておく：

| 見るところ | なぜ |
|---|---|
| 柔らかいシート（熱伝導シート）を貼る場所 | チップの熱をケースに伝える。貼り忘れると冷えない |
| ファンの線を、**どのピンに挿すか** | ボタンとぶつからないか確かめるため |

ファンの線の挿し先を、ここにメモする：

| ファンの線 | 挿すピン |
|---|---|
| 赤（＋） | 4番（5V） |
| 黒（−） | 6番（GND） |

- このケース（AK-RS-02）は説明書が入っていなかった（2026-11-27）。
  ファン2つの線が1つのコネクタ（穴2つ）にまとまっていて、
  外側の列の上から2本目・3本目にそのまま挿せた

- よくあるのは、赤＝4番（5V）、黒＝6番（GND）
- 2つのファンで線が2組あるときは、両方メモする

⚠️ 挿したら、**電源を入れる前に写真を撮って Claude に見せる**。
ピンを1つずれると、ラズパイが壊れることがあるため。

## 6. ボタンをつなぐ

### 6-1. ピンの場所

microSD カード側のはしから数える。

```
   内側        外側（基板のふち）
   1 ●        ● 2   5V（さわらない）
   3 ●        ● 4   5V（さわらない）
   5 ◎        ● 6   GND
   ↑ボタン
   7 ●        ● 8
   9 ◎        ● 10
   ↑ボタン（GND）
```

| ピン | 名前 | 役わり |
|---|---|---|
| 5番 | GPIO3 | ボタンを見張るピン（決まっている） |
| 9番 | GND | 電気の帰り道 |

- GND ＝ ground ＝ 地面。電気の帰り道
- 9番がファンでふさがっていたら、14・20・25番も GND なので、
  そこを使う

### 6-2. スイッチをブレッドボードに挿す

```
  タクトスイッチ（上から見た図）
   足A ●──────● 足B
       │ ボタン │
   足C ●──────● 足D
```

- 足は4本。中で2本ずつつながっている
- **ななめの2本（足A と 足D）**を使えば、向きをまちがえても動く

ブレッドボードの穴は、列ごとに中でつながっている。
スイッチの足A と 足D が、**別々の列**に入るように挿す。

### 6-3. 線を2本つなぐ

```
 足A と同じ列 ── 線1 ── 5番ピン（GPIO3）
 足D と同じ列 ── 線2 ── 9番ピン（GND）
```

- 線のオス（針）をブレッドボードに、メス（穴）をラズパイのピンに挿す
- 線は全部黄色なので、線1 のはしにマスキングテープを巻いて、
  見分けられるようにする

⚠️ ここでも、**電源を入れる前に写真を撮って Claude に見せる**。

## 7. 動くか確かめる

### 7-1. 電源を入れる

新しい AC アダプターの USB-C を挿す → 1〜3分待つ → Mac から `ssh homepi` で入れたら OK。

**確かめる**：ファンが回っている。

### 7-2. ボタンで電源を切る

ボタンを1回、短く押す。

**確かめる**：
- SSH が切れる（`Connection closed` など）
- 少しして、緑ランプが止まる

### 7-3. ボタンで起動する

USB-C は**挿したまま**、もう一度ボタンを押す。

**確かめる**：緑ランプがチカチカして、1〜3分後に `ssh homepi` で入れる。

小ネタ：ラズパイ4 は、止まっている間も 5番ピン（GPIO3）だけは
見張っている。だから同じボタンで「つける」もできる。

### 7-4. 日記で確かめる（読むだけ）

```bash
journalctl -b -1 --no-pager | grep -i "power key"
```

| 部分 | 意味 |
|---|---|
| `journalctl` | ラズパイの日記（ログ）を読む |
| `-b -1` | boot。1回前に起動していたときの日記 |
| `--no-pager` | 1画面ずつ止めずに、全部出す |
| `grep -i "power key"` | 大文字小文字を区別せず（`-i`＝ignore case）、power key の行だけ |

**確かめる**：`Power key pressed` のような行が出る。
＝「電源ボタンが押されたので、きちんと電源を切った」記録。

### 7-5. 電気が足りているか見る

新しい AC アダプターに替えたので、ここも確かめる。

```bash
vcgencmd get_throttled
```

- `get_throttled` ＝ 速さを落としたことがあるか聞く

**確かめる**：`throttled=0x0` なら、電気も熱も問題なし。

### 7-6. 温度を見る

```bash
vcgencmd measure_temp
```

- `vcgencmd` ＝ VideoCore general command ＝ チップに直接聞く
- `measure_temp` ＝ 温度を測る

**確かめる**：50℃ くらいまでなら、よく冷えている。
数字をここにメモする：

| いつ | 温度 |
|---|---|
| 組み立て前（ケースなし・起動して4分。2026-11-27） | 39.9℃ |
| 組み立て後（ケース＋ファン） | 未記入 |
